# Mini-8 RTL — VHDL-2008

Este diretório contém a proposta de implementação RTL e um testbench para os exemplos soma e laço.

Pré-requisito: GHDL com suporte a VHDL-2008.

```bash
cd hdl
sh run_ghdl.sh
```

O testbench deve emitir `Mini-8 RTL testbench: PASS` quando todas as asserções forem satisfeitas. Se falhar, **não considere o RTL validado**.

**Estado:** fontes publicadas, compilação e simulação HDL ainda não confirmadas neste projeto. O período de 10 ns do testbench é arbitrário, não uma medição de frequência máxima.
