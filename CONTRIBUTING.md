# Contribuição

O Mini-8 é um projeto acadêmico de Ezequias Ferreira e Marcelo Barbosa.

Ao propor alterações:
1. Preserve a semântica da ISA de 8 bits documentada.
2. Adicione testes para instruções, registradores e acessos à memória.
3. Distinga resultados verificados de hipóteses e etapas ainda pendentes.
4. Abra uma issue ou pull request com descrição técnica e evidências de teste.

A execução dos testes Python não deve ser apresentada como validação do RTL VHDL.
